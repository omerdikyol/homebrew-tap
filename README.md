# omerdikyol/homebrew-tap

Homebrew casks for [fener](https://fener.omerdikyol.com), the keyboard launcher for macOS you
configure in text.

```sh
brew install --cask omerdikyol/tap/fener
```

`brew upgrade` keeps it current. `brew uninstall --zap fener` also removes its settings,
history and caches.
